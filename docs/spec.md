# 顯示規格

> ⚠ 這份還是最早「卡片盒」版本的寫法，部分過時。最新畫法以 `hcard.js` 和 [`progress.md`](progress.md) 為準；資料欄位、演算法、app 相關程式的說明仍可參考。

路況頁與主畫面共用同一個**卡片**元件。畫法以 `hcard.js` 為準，這份文件說明每條規則的意思、資料從哪來、怎麼算。

## 1. 名詞

| 名詞 | 意思 |
|---|---|
| 卡片 | 一個交流道（節點 i）＋它到下一個交流道的路段（i → i+1）。最後一個交流道只有表頭。 |
| 直行 | 沿著目前道路走。卡片由上往下排＝里程增加的方向。 |
| dirA／往下走 | 里程增加的方向：南下（S）、東向（E）。速度框標 ▼。 |
| dirB／往上走 | 里程減少的方向：北上（N）、西向（W）。速度框標 ▲。 |
| 接 | 在交流道轉到另一條國道／快速公路（資料上的一筆 `link2s`）。 |
| 走到底 | 目前道路在這個方向的終點。 |
| 出口 | 轉入後 2 km 內就到那個方向終點的「接」，只寫「出口 往 XX」。 |
| 聚焦 | 只看一個行駛方向：另一方向變淡，轉向也只列這個方向能用的。 |

## 2. 卡片結構（由上到下）

1. **表頭**：交流道名稱、里程膠囊（`{showKm} km`）、休息站標籤、目前位置標籤（主畫面）、右側距離與時間（主畫面）。
2. **上緣終點線**：只在往上走方向走到底的那張卡（第一張卡）。見 §5。
3. **路面**：
   - **直行的路**：速度框後面一條垂直的灰色路（`#4d5055`），左右路邊線 `#b8bbc0`，中央雙黃線 `#E5B300` 從上貫穿到下。
   - **速度框**兩個：左邊是往上走（dirB，標 `方向 ▲`），右邊是往下走（dirA，標 `方向 ▼`）。內容：方向、車速（整數）、`km/h`。底色是路況顏色。
   - **兩側接其他道路**：見 §4。
4. **下緣終點線**：只在往下走方向走到底的那張卡（最後一張卡，表頭下面）。
5. **裝置列**（路況頁）：CCTV、CMS、事件小標籤，後面註明方向。

尺寸（路況頁，寬 342 的卡片內部；主畫面乘 0.76）：路面高 92、橫向車道高 62、速度框 48×76、速度框與中線距 13、兩側欄寬 58、每塊直排路牌約 78 高、終點線列高 44。

顏色：畫面底 `#1C1D20`、卡片 `#24262A`、邊框 `#3b3d42`、路牌 `#0B6E3F`（白框）、「到底／終點」字 `#ffcf7a`。路況顏色沿用 app 的 `TrafficLiveModel.getTrafficColor()`（mockup 為了示意改用車速分級）。

## 3. 資料

來源：`RoadSectionModel.link2s`（`lib/model/RoadSectionModel.dart`，`RoadSectionLinkModel`）。

| 欄位 | 意思 |
|---|---|
| `roadID`、`roadName` | 目標道路 |
| `dir` | **目標道路**的方向（N/S/E/W）。畫面上一定要顯示這個方向。 |
| `interchangeName` | 在哪個交流道接 |
| `sectionID` | 轉入後的第一段（目標道路的 section） |

規則：

- **一筆 link 屬於「目前方向抵達該交流道」**：dirA 的 section `…→i` 的 link 是 dirA 在交流道 i 能接的；dirB 的 section `i+1→i` 的 link 是 dirB 在交流道 i 能接的。
- **抵達的方向**：第一個交流道只有 dirB 抵達，最後一個只有 dirA 抵達，其他兩個方向都抵達。
- **去重用 `roadID + dir`**，並記下哪些方向（車道）能接。app 現在依 `roadID` 去重（`_linksAtEndpoint`、`_uniqueRoadLinks`），會把「61 北上」「61 南下」合併成一個，全路網 163 組中有 98 組因此少了一個方向。
- 範圍：`link2s` 只含國道與快速公路之間的轉接（全路網 261 筆），一般道路出口不在資料裡。

## 4. 兩側：接其他道路

- **放哪一側**：目標道路在卡片的**地圖方位**。卡片由上往下＝里程增加方向，所以：目標在「里程增加方向」的**左手邊**→畫在卡片**右側**；在**右手邊**→畫在**左側**。對往上走的駕駛，這正好是他自己的左右；往下走的駕駛看到的左右和他自己的相反（已定案照地圖固定，見 decisions.md）。算法見 §7.1。
- **只畫能接的那一側**：那一側從直行的路延伸一段**橫向車道**（灰底、上下與中間實線、兩條虛線）到卡片邊緣的路牌，接口處直行路的路邊線斷開。沒得接的一側連車道都不畫。
- **路牌**（直排）：盾牌圖、目標方向（例如「南下」）、`往 XX`；路牌下方一個朝外的水平箭頭（左側 ←、右側 →）。
- **不是每個抵達方向都能接**時，路牌下註明「僅北上」（列出能接的方向）。聚焦模式不需要這行。
- 同一側有多個目標就直向堆疊，路面高度加高（每塊約 78）。
- 點路牌：跳到目標道路、目標方向，捲到該交流道（取代原本表頭的「[61] ›」，沿用 `_openRoadSectionLink`，把 `dir` 帶過去）。

## 5. 走到底

- **判斷**：dirB 在第一個交流道走到底；dirA 在最後一個交流道走到底，但只有它是道路真正的終點時才算（資料被截斷的列表不算）。
- **畫在前方**：dirB 的終點線畫在第一張卡的表頭下面（上緣）；dirA 的畫在最後一張卡的表頭下面（下緣）。兩側欄不畫這個交流道的轉向。
- **有得轉**：一條水平白線，中間標籤「{方向}到底」；能轉的路牌（橫排：盾牌＋方向＋往 XX）放在線的左端或右端（左右規則同 §4），線端有朝外的箭頭。**只能轉一邊**：另一端畫直立擋線，而且擋線要在中間標籤外面（離中心 = 標籤半寬 + 12），看得出那邊不能轉。
- **沒得轉**：短白線兩端直立擋線，中間「{方向}終點」。

## 6. 出口（轉入後馬上到底）

- **判斷**：`remainKm ≤ 2`。`remainKm` 算法見 §7.2。全路網目前符合的：國3 木柵→國3甲東向（0.6 km，深坑端）、國3 新化系統→國8 東向（1.3 km，新化端）、國3 竹田系統→台88 東向（1.6 km，竹田端），兩個方向各一筆。
- **畫法**：路牌不放盾牌、不寫方向，只寫「出口」＋「往 XX」（XX＝該方向終點名稱，去掉「端」，例如深坑）。位置、箭頭、橫向車道和一般的接一樣。
- 小條、終點線上的出口也照這個寫法。

## 7. 演算法

### 7.1 左右

1. 取目前道路**里程增加方向**在交流道附近的方位角 `hCur`：拿抵達交流道的那個 section 最後幾個座標點（約 6 點）算起點到終點的方位角；如果那個 section 是 dirB，方位角加 180°。
2. 取目標 section（`link.sectionID`）開頭幾個座標點算方位角 `hTgt`。
3. `rel = ((hTgt − hCur + 540) mod 360) − 180`。
4. `|rel| < 30` 或 `> 150` 視為**平行**（全路網 27 筆，例如國1／國3 在汐止），預設畫右側。其餘 `rel < 0`（在左手邊）→卡片右側，`rel > 0`→左側。
5. 取樣長度會影響邊界值（中和、瑪東系統換成 2 km 取樣會落到平行門檻）；用靠近交流道約 0.5 km 內的點。
6. 建議打包 `freeways_all` 時先算好存成 `link.side`（`L`／`R`），app 不用在執行時算。參考實作：`tools/link_geometry.py`。

### 7.2 剩餘里程

`remainKm = |目標方向最遠終點里程 − 目標 section 起點里程|`；目標方向是 S/E 時取該方向所有 section 的 `endKm` 最大值，N/W 取最小值。同樣建議打包時算好存成 `link.remainKm`。

### 7.3 往 XX

mockup 用手寫對照表（`shared.js` 的 `TOWARD`）。實作時請改用資料：優先用後端提供的控制地名；沒有就用目標方向終點的名稱（去掉「端」）。

## 8. 主畫面

- **同一個卡片元件**，尺寸乘 0.76，聚焦目前行駛方向：另一方向的路面半邊與速度框透明度 0.28，轉向只列目前方向能用的。
- **取哪幾張卡**：從目前所在路段那張卡（`curSeg`）往行進方向取 3 張。往下走：`to = min(last, curSeg+2)`、`from = max(0, to−2)`；往上走：`from = max(0, curSeg−2)`、`to = min(last, from+2)`。往下走一定要能取到最後一張卡（下緣終點線在那裡）。
- **已經開過的交流道不標轉向**：只有前方還沒到的交流道畫兩側與終點線。
- **目前位置**：在 `curSeg` 那張卡的表頭放「▲／▼ 目前 12.3K」標籤。
- **表頭右側**：到該交流道的距離與時間（前方的才顯示）。
- **小條**（有事件時的 80 高橫條）：寫前方第一個「能接或走到底」的交流道。有得接：「{交流道}{到底?} ←[路牌] [路牌]→」（路牌小尺寸，空間不夠省略往 XX；出口仍寫「出口 往 XX」）；沒得接的終點：「{交流道} {方向}終點」。
- 放大／縮小只改尺寸，畫法和路況頁完全相同。

## 9. 已知限制

- 平行的轉接（10%）一律預設右側，可能和實際方位不符。
- mockup 的車速顏色分級、「往 XX」、`REMAIN_KM`、`GEO` 都是手寫示意，實作要用資料算。
- 路網資料有命名不一致（例如「永安→新豐一」的下一段叫「57新豐一」），判斷連續路段時用里程，不要用名稱比對。
